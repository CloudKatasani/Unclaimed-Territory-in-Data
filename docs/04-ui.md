# 04 — UI

Single-page React app, left nav, user switcher in the header (alice / raj / admin) for the demo.

## Ask (default screen)

- Question box with 4 suggested questions from the storyline.
- Result: table + simple bar/line chart when the result has one measure over a dimension or time.
- Certificate panel beside the result:
  - verdict badge (release / with warning / block) and the rule that set it
  - metrics with certified tick and certifier
  - policies applied, shown as plain sentences ("Filtered to region NORTH for alice")
  - freshness and quality per product
  - "Built by" strip: each lineage node colored human / agent-approved / agent-unapproved
  - "Verify" button: calls `/certs/{id}/verify`, shows signature valid + chain intact
- When outcome is `missing_data`: friendly message, the unmatched terms, and "We've logged this —
  you'll be notified when it can be answered."

## Demand Board

- Cards per intent: label, demand score, askers, sample questions, gap type, candidate join path drawn
  as a small chain of entity chips.
- "Draft contract" (if not drafted), "View contract" (YAML viewer with diff vs. last version).
- Raj sees Approve / Reject. Approval emits `contract.approved`.
- Closure column: questions resolved / total after publish.

## Builds

- Job list with status timeline: drafted → generating → testing → gate → published.
- Detail: generated SQL (read-only, syntax highlighted), derived tests with pass/fail, repair attempts,
  provenance record JSON.

## Drift

- Event list. Detail view is the centerpiece of ID-2:
  - change list (rename / type change)
  - blast radius graph: affected objects colored by criticality
  - candidate table: candidate, max divergence, threshold, pass/fail per object
  - evidence drill-down: per-column metrics baseline vs candidate
  - action buttons for held patches (Raj): approve, reject

## Lineage

- Graph explorer (react-flow or elkjs) from any product to raw, nodes badged with provenance status.

## Marketplace (new default screen for business users)

- Three rows: Decision packs, Data products, Agents. Cards carry the evidence strip from `06-marketplace.md`.
- Detail drawer: contract (YAML viewer), evidence history chart, Subscribe / Unsubscribe, thresholds with current margin for packs.

## Agent store

- Agent cards sorted by verified accuracy; trial strip and Promote button when a trial exists; version history with evaluation signatures.

## Access panel

- Leases grouped by bundle, each with scope, purpose and expiry; budget consumption bar.

## Inbox

- Recall notices with old/new values, reason, and "Open original answer"; acknowledge clears the Ask banner.

## Pipeline truth

- Sentinel matrix: rows = sentinel records, columns = products; green/red cells with expected vs actual on hover.

## Design notes

- Calm enterprise look; one accent color; status colors only for verdicts and pass/fail.
- Every number on screen comes from the API; no hard-coded figures.
- Works at 1280px and 1920px; phone not required.
